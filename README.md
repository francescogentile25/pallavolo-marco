# Pallavolo Marco

Applicazione mobile-first per organizzare partite, tornei e attività della community di beach volley.

## Sviluppo locale

```bash
npm install
npm start
```

L'applicazione richiede un progetto Supabase configurato tramite gli environment Angular.
